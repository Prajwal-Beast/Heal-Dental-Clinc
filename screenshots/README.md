# Screenshots — Design Review Folder

Save screenshots of each section here after running the site locally.
Claude can read these images directly in future sessions to review layout, spot issues, and suggest improvements.

| File | Section |
|------|---------|
| `01-nav-desktop.png` | Navigation bar (desktop) |
| `02-hero.png` | Hero section full view |
| `03-stats.png` | Stats bar |
| `04-about.png` | About section |
| `05-services.png` | Services card grid |
| `06-team.png` | Team cards |
| `07-reviews.png` | Google reviews |
| `08-contact.png` | Booking form + contact info |
| `09-footer.png` | Footer |
| `mobile-nav.png` | Mobile nav overlay |
| `mobile-hero.png` | Hero on mobile |
| `full-page.png` | Full page scroll screenshot |

## How to take screenshots

- **Windows:** Snipping Tool, or `Win + Shift + S`
- **Full page:** Use browser DevTools → `Ctrl+Shift+P` → "Capture full size screenshot"
- **Mobile simulation:** DevTools → Toggle device toolbar → capture

## How to use with Claude

Drag a screenshot into the Claude chat, or reference the path. Claude will read the image and suggest specific CSS/HTML fixes.
